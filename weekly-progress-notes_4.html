Set Up Real-Time Sync

Follow these steps to connect your free Firebase database. Once done, all staff share data in real time from any device.

Step 1 — Go to firebase.google.com → sign in with any Google account
Step 2 — Go to console → Add project → name it anything → click through
Step 3 — Click Realtime Database → Create Database → pick any location → Start in test mode
Step 4 — Click ⚙️ gear → Project settings → scroll to Your apps → click </> (Web) → register → copy the 3 values below

Your config is saved in this browser. Repeat this step on each new device — takes 30 seconds.
