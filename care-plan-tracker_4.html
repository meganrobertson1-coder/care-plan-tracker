Set Up Real-Time Sync

Follow these 3 steps to connect your free Firebase database. Once done, all staff will share data in real time from any device.

Step 1 — Go to firebase.google.com and sign in with any Google account
Step 2 — Click Go to console → Add project → name it anything → click through
Step 3 — In your project: click Realtime Database → Create Database → choose any location → start in test mode
Step 4 — Click the ⚙️ gear → Project settings → scroll to Your apps → click </> (Web) → register app → copy the 3 values below

Your config is saved in this browser. To connect other devices, open the file there and repeat this step.
